# [반례 91] `agent_runtime=None` — 프로덕션에 없는 조합을 테스트가 만들었다

- **분류**: 🔴 반례
- **발견**: 2026-09-14
- **해당 파일**: `test_outline_observability.py`, `test_scaffold_observability.py`
- **놓친 것**: 비용 원장 기록 · 실패 정산 · 재개 등록이 **한 번도 실행되지 않음**

---

## 1. 코드

### 프로덕션 쪽 — 모든 협력자가 선택적

```python
class ExtractOutlineUseCase:
    def __init__(
        self,
        source: OutlineDocumentSourcePort,
        artifacts: OutlineArtifactRepository | None = None,
        cache: Any = None,
        agent_runtime: AgentRuntimePort | None = None,
        recorder: ExecutionRecorder | None = None,
        llm_harness: BaseLlmHarness | None = None,
        telemetry: OutlineTelemetryPort | None = None,
        engine: OutlineExtractPort | None = None,
        archive: OutlineArchivePort | None = None,
    ) -> None:
        ...
        # 포트-어댑터 기본 조립 (직접 주입되지 않은 경우 자동 구성)
        if engine is not None:
            self._engine = engine
        elif llm_harness is not None and cache is not None:
            self._engine = EngineOutlineExtractAdapter(harness=llm_harness, cache=cache)
        else:
            self._engine = None  # type: ignore
```

### 테스트 쪽 — 그래서 이렇게 쓸 수 있었다

```python
use_case = ExtractOutlineUseCase(
    source=source_repo,
    engine=engine_adapter,
    archive=archive_adapter,
    telemetry=test_telemetry,
)                      # agent_runtime 없음, llm_harness 없음
```

```python
use_case = GenerateScaffoldUseCase(
    source=source_repo,
    scaffolds=archive_service,
    agent_runtime=None,        # ← 명시적으로 None
    engine=engine_adapter,

```

## 2. 무엇이 잘못됐나

컨테이너는 **항상** 모든 협력자를 주입한다. 즉 `agent_runtime=None` 인 유스케이스는
**프로덕션에 존재하지 않는다.** 그런데 테스트가 그 조합을 만들어 통과시켰다.

코드에는 `None` 을 견디는 분기가 곳곳에 있었다.

```python
if self._runtime:
    self._runtime.record_cost(run_id, cost)      # 테스트에서는 항상 건너뜀
```

```python
def _settle_failure(self, run_id, doc_id, telemetry) -> None:
    if not self._runtime:
        return                                    # 테스트에서는 항상 여기서 반환
```

**테스트가 지나간 적 없는 코드가 프로덕션의 주 경로였다.**

---

## 3. 그래서 놓친 것

| 놓친 것 | 실제 결과 |
| --- | --- |
| `record_cost()` 호출 | 비용 원장(`data/ledger/`)이 **9월 12일에 멈춤** — run 은 14일까지 계속됨 |
| `settle_failure()` 호출 | 대기 상태 전이가 검증된 적 없음 |
| 재개 핸들러 등록 | outline·wireframe 이 **재개 불가**인 채로 방치 |

원장이 멈춘 것을 아무도 몰랐던 이유: 관측 화면이 원장이 비면 **텔레메트리 합산으로
폴백**하고 있었다. 숫자가 보이니 정상으로 보였다.

> `if self._runtime:` 은 방어 코드처럼 보이지만, 실제로는 **"이 협력자가 없어도 된다"는
> 거짓 계약**을 만든다. 그리고 그 거짓을 유일하게 사용하는 것이 테스트였다.

## 4. 올바른 형태

### 협력자는 전부 필수로

```python
class ExtractOutlineUseCase:
    def __init__(
        self,
        source: OutlineDocumentSourcePort,
        engine: OutlineExtractPort,
        archive: OutlineArchivePort,
        agent_runtime: AgentRuntimePort,
        telemetry: OutlineTelemetryPort,
        llm_harness: BaseLlmHarness,
    ) -> None:
        """협력자는 전부 필수다. **유스케이스는 어댑터를 고르지 않는다.**

        조립 오류는 요청이 아니라 부팅이 발견해야 한다.
        """
```

`if self._runtime:` 분기가 전부 사라진다. 코드가 짧아지는 것은 부수 효과고,
본질은 **거짓 계약이 없어지는 것**이다.

### 테스트는 대역이 아니라 실물을 쓴다

```python
def _runtime(tmp_path: Path):
    """실제 Agent Runtime. 대역이 아니라 본 물건을 쓴다.

    유스케이스의 협력자가 전부 필수가 된 뒤로, 런타임 없이 만든 유스케이스는
    프로덕션에 존재하지 않는 조합이 되었다. 그런 조합을 테스트가 만들어 내면
    테스트는 자기가 지어낸 세계를 검증한다.
    """
    from agent_runtime import AgentRuntime, LocalAgentRunRepository, LocalLedger

    return AgentRuntime(
        runs=LocalAgentRunRepository(tmp_path / "runs"),
        ledger=LocalLedger(tmp_path / "ledger"),
    )
```

## 5. 언제 대역을 쓰고 언제 실물을 쓰나

| 협력자 | 판정 | 이유 |
| --- | :---: | --- |
| `AgentRuntime` + 로컬 저장소 | **실물** | 순수 로컬·빠름. 대역을 쓰면 이벤트 폴드가 검증 안 됨 |
| LLM 하네스 | **대역** | 외부 프로세스/네트워크. 차단 지점이 고정돼 있음 |
| OS 키링 | **대역** | 개발 PC 의 실제 자격 증명을 건드림 |
| 문서 저장소 | **실물**(tmp) | 파일 레이아웃이 검증 대상의 일부 |

정본: [`../spec/05.fixtures/01.doubles-policy.md`](../spec/05.fixtures/01.doubles-policy.md)

---

## 6. 교훈

> **협력자를 `None` 으로 둘 수 있다면, 그 조합이 프로덕션에 있는지 먼저 물어라.**
> 없다면 그것은 유연성이 아니라 **검증되지 않는 분기**다.
