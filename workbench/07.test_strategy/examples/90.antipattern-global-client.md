# [반례 90] 전역 `TestClient` — lifespan 이 돌지 않는 앱을 검증했다

- **분류**: 🔴 반례
- **발견**: 2026-09-14
- **해당 파일**: `test_inspector.py`, `test_observability_contract.py`,
  `test_payload_externalization.py`, `test_scaffold_observability.py` (4개 모듈)
- **놓친 버그**: **새 설치가 부팅되지 않음** (`StorageVersionError`)

---

## 1. 코드

```python
# 모듈 최상단
from main import app

client = TestClient(app)        # ← with 가 없다
```

한눈에 문제가 없어 보이고, 실제로 요청은 정상적으로 처리된다. 그래서 4개 모듈이
같은 방식으로 자랐다.

---

## 2. 무엇이 잘못됐나

`TestClient(app)` 을 **`with` 없이** 쓰면 **lifespan 이 실행되지 않는다.**
즉 이 4개 모듈의 테스트가 상대하는 앱은:

| 부팅이 해야 할 일 | 전역 client 에서 |
| --- | --- |
| 저장된 실행 정책 복원 | ❌ 안 함 |
| 재개 핸들러 3건 등록 | ❌ 안 함 |
| 끊긴 실행(고아) 정리 | ❌ 안 함 |
| 만료 로그 정리 | ❌ 안 함 |

**프로덕션에 존재하지 않는 상태다.** 라우터만 붙어 있는 껍데기를 검증하고 있었다.

---

## 3. 그래서 놓친 것

`main.py` 의 부팅 순서가 이랬다.

```python
settings.ensure_directories()     # ① 등급 루트를 만든다
...
verify_storage_version()          # ② 버전을 확인한다
```

`verify_storage_version()` 은 *"버전 파일이 없고 저장소가 비어 있으면 새 설치"* 로 판정한다.
그런데 ①이 먼저 돌아 `data/` `cache/` `state/` 를 만들어 버리므로 **`is_empty()` 가 항상
거짓**이 된다. 결과:

```text
StorageVersionError: 저장소 레이아웃 버전이 맞지 않습니다 (디스크=None, 코드=4).
```

**갓 클론한 저장소는 부팅이 거부된다.** 테스트 131개가 전부 초록인 채로.

### 왜 안 잡혔나

- 개발 PC 에는 이미 `data/.storage_version` 이 있어 이 경로를 밟지 않는다.
- 테스트는 lifespan 을 돌리지 않으므로 부팅 순서를 아예 실행하지 않는다.
- 이 버그는 **테스트 저장소를 격리하고 나서야** 드러났다 (빈 저장소가 처음 생겼으므로).

## 4. 올바른 형태

```python
# conftest.py
@pytest.fixture(scope="session")
def api_client():
    """lifespan 을 실제로 실행한 클라이언트. 세션당 한 번만 부팅한다."""
    from fastapi.testclient import TestClient
    import main

    with TestClient(main.app) as client:      # ← with 가 부팅을 돌린다
        yield client
```

```python
# 테스트
pytestmark = pytest.mark.wiring

def test_inspector_lists_runs(api_client) -> None:
    assert api_client.get("/api/v1/inspector/runs").status_code == 200
```

| | 전역 client | `api_client` 픽스처 |
| --- | --- | --- |
| lifespan | ✗ | **✓** |
| 부팅 비용 | 모듈 임포트 시 | 세션 1회 (1.6초) |
| 등급 표시 | 없음 | `wiring` 마커 |
| 부팅 순서 버그 | **못 잡음** | 잡음 |

---

## 5. 교훈

> **테스트는 프로덕션에 존재하는 조합만 만든다.**

lifespan 없는 FastAPI 앱은 프로덕션에 없다. 그런 객체를 만들어 검증하면, 그 테스트는
**자기가 지어낸 세계**를 검증한다. 통과해도 아무것도 보장하지 않는다.

같은 뿌리의 다른 반례: [`91.antipattern-none-collaborators.md`](./91.antipattern-none-collaborators.md)
