## 2. 고정 차단 지점

### 경계 1 — CLI 하네스

```python
monkeypatch.setattr(AgyCliHarness, "run_structured", fake_run)
```

| | |
| --- | --- |
| **지점** | `llm_driver.AgyCliHarness.run_structured` |
| **왜 여기** | 어댑터의 **유일한 필수 구현 메서드**다. `run_text`/`run_json` 은 이것을 호출하므로 한 곳만 막으면 전부 막힌다 |
| **더 아래는?** | `subprocess.Popen` 을 막으면 명령 조립까지 검증하게 되어 테스트가 CLI 인자 포맷에 묶인다 |

### 경계 2 — Google REST

```python
monkeypatch.setattr("llm_driver.adapters.gemini.requests.post", fake_post)
```

| | |
| --- | --- |
| **지점** | `llm_driver.adapters.gemini.requests.post` |
| **왜 여기** | 요청 본문·스키마 조립까지 검증하면서 네트워크만 끊는다 |
| **대안** | 하네스 레벨(`GoogleGenAiHarness.run_structured`)은 **요청 조립을 건너뛴다**. 구조화 출력 스키마를 검증할 때는 `requests.post` 를 써야 한다 |

> 둘 다 유효하다. **무엇을 검증하느냐**로 고른다.
> - 라우팅·정책 검증 → 하네스 레벨
> - 요청 본문·스키마 검증 → `requests.post`

### 경계 3 — OS 키링

```python
container.credential_store.override(providers.Object(_FakeCredentialStore()))
```

| | |
| --- | --- |
| **지점** | 컨테이너 `credential_store` provider |
| **왜 여기** | `monkeypatch` 가 아니라 **주입**으로 막는다. 포트가 이미 있다 |
| **대역 규칙** | 쓰기·삭제는 `AssertionError` 로 거부 → [`01.doubles-policy.md`](./01.doubles-policy.md) §4 |

### 경계 4 — 사용자 홈

```python
container.agy_status_line_settings.override(providers.Object(None))
# 또는 tmp_path 를 가리키는 실물
LocalAgyStatusLineSettings(settings_file=tmp_path / "settings.json", bridge_command="...")
```

| | |
| --- | --- |
| **지점** | 컨테이너 `agy_status_line_settings` provider |
| **왜 여기** | 경로가 생성자 인자다. **주입으로 tmp 로 돌릴 수 있다** |

## 3. 부수 지점

| 지점 | 언제 | 주의 |
| --- | --- | --- |
| `shutil.which` | CLI 설치 여부 판정 | 모듈 경로로 지정: `"app.llm_settings.service.shutil.which"` |
| `HarnessFactory._builders` | 하네스 빌더 전역 등록 | **원복 필수** — `LlmManager` 생성이 전역 팩토리에 등록하므로 다른 테스트로 샌다 |

```python
# 전역 오염 방지 — 사본으로 교체해 두면 테스트 후 자동 원복된다
monkeypatch.setattr(HarnessFactory, "_builders", dict(HarnessFactory._builders))
```

---

## 4. 막으면 안 되는 것

| 막지 말 것 | 이유 |
| --- | --- |
| 파일 I/O (`open`, `Path.write_text`) | `tmp_path` 로 이미 격리된다. 막으면 저장 레이아웃이 검증에서 사라진다 |
| `datetime.now` | 시각이 검증 대상이면 인자로 주입받게 설계를 고친다 |
| 내부 서비스 메서드 | 포트 대역으로 주입한다 → [`01.doubles-policy.md`](./01.doubles-policy.md) §6 |
| **전역 `settings` 속성** | 프로세스 전역 상태를 바꾼다. 주입된 `RuntimeExecutionPolicy` 를 쓴다 |

## 5. 점검 명령

```bash

grep -rn "monkeypatch.setattr" apps/api/tests/*.py

# 실제 외부 호출 흔적이 남았는가 (테스트 후)
grep -rn "requests.post\|subprocess.Popen" apps/api/tests/*.py
```

기대 결과:

- `monkeypatch.setattr` 는 §2·§3 의 지점만 나온다
- 테스트가 직접 `subprocess` 를 쓰는 곳은 **의도적으로 브리지 스크립트를 실행하는 하나**
  (`test_agy_status_snapshot.py`)뿐이며, 이 테스트는 `external` 마커를 단다

## 6. 새 외부 경계가 생기면

1. 이 문서에 **경계와 지점**을 추가한다.
2. 지점은 **포트가 있으면 주입**, 없으면 `monkeypatch` — 포트를 만들 수 있는지 먼저 본다.
3. 고정표에 없는 지점을 쓴 테스트는 리뷰에서 되돌린다.

> 포트를 만들 수 있는데 `monkeypatch` 로 때우면, 그 순간 **프로덕션 코드의 결함**
> (교체 불가능한 의존)을 테스트가 숨겨 주게 된다.
