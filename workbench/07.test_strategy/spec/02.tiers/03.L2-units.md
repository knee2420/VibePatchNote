## 필수 3종

파일·식별자를 다루는 어댑터는 **세 가지를 갖춘다.**

| 종류 | 질문 | 없으면 |
| --- | --- | --- |
| **정상 경로** | 하기로 한 일을 하는가 | — |
| **부재·손상** | 없을 때 / 깨졌을 때 어떻게 답하는가 | "없음"이 예외로 올라와 정상 흐름에서 잡히고, 진짜 실패가 섞인다 |
| **과행동 방어** | 대상이 **아닌 것**을 건드리지 않는가 | 삭제·갱신이 남의 데이터까지 먹는다 |

식별자로 경로를 만드는 어댑터는 **넷째**가 추가된다.

| **식별자 안전성** | `../` 같은 이름을 거부하는가 | 저장 루트 밖을 읽거나 지운다 |

실제 예: [`examples/02.L2-run-observation-store.md`](../../examples/02.L2-run-observation-store.md)

## 대역 vs 실물

**대역은 외부 경계에서만 쓴다.** 내부 객체는 실물을 쓴다.

| 협력자 | 판정 | 이유 |
| --- | :---: | --- |
| `AgentRuntime` + 로컬 저장소 | **실물** | 순수 로컬·빠름. 대역을 쓰면 이벤트 폴드가 검증 안 됨 |
| 문서 저장소 어댑터 | **실물**(`tmp_path`) | 파일 레이아웃이 검증 대상의 일부 |
| LLM 하네스 | **대역** | 외부 프로세스·네트워크 |
| OS 키링 | **대역** | 개발 PC 의 실제 자격 증명 |
| 다른 도메인의 서비스 | **대역**(포트 구현) | 그 도메인의 행동은 그쪽 테스트가 본다 |

정본: [`../05.fixtures/01.doubles-policy.md`](../05.fixtures/01.doubles-policy.md)

## 협력자는 비우지 않는다

```python
# ✗ 프로덕션에 없는 조합
use_case = ExtractOutlineUseCase(source=repo, engine=engine, telemetry=tel)
#                                            ↑ agent_runtime 없음

# ✓ 컨테이너가 만드는 것과 같은 조합
use_case = ExtractOutlineUseCase(
    source=repo, engine=engine, archive=archive,
    agent_runtime=_runtime(tmp_path),      # 실물
    telemetry=tel, llm_harness=_StubHarness(),
)
```

> `agent_runtime=None` 조합이 비용 원장 중단을 2일간 숨겼다.
> → [`examples/91.antipattern-none-collaborators.md`](../../examples/91.antipattern-none-collaborators.md)

## 저장 루트는 주입받는다

```python
# ✓ 루트를 준다
store = RunObservationStore(tmp_path / "runs")

# ✗ 실제 저장소를 쓴다
store = RunObservationStore(settings.storage.runs)
```

두 번째가 가능하다는 것 자체가 **어댑터 설계의 결함**이다. 어댑터가 경로를 스스로 열면
테스트는 실제 `data/` 에 쓸 수밖에 없다.
→ [`examples/92.antipattern-real-data.md`](../../examples/92.antipattern-real-data.md)

## 비동기 스타일

새 비동기 테스트는 **`@pytest.mark.anyio`** 로 통일한다.

```python
@pytest.mark.anyio
async def test_...():
    ...
```

> 현재 `asyncio.run()` 을 쓰는 파일이 둘 있다. 백그라운드 태스크를 여러 번 돌려야 하는
> 시나리오(`await asyncio.sleep(0)` 반복)라면 `asyncio.run()` 이 읽기 쉬울 수 있다.
> 그런 경우 **왜 그 스타일인지 주석으로 남긴다.**
