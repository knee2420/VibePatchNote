## 1. 결정 표 — 새 테스트는 여기서 등급이 정해진다

**위에서부터 순서대로** 묻는다. 먼저 "예"가 나오는 곳에서 멈춘다.

| # | 질문 | 예 | 아니오 |
| :---: | --- | --- | --- |
| 1 | 코드를 **실행하지 않고** 증명되는가? (import 그래프·파일 배치·설정) | **L0** — pytest 아님 | ↓ |
| 2 | **앱을 부팅**해야 하는가? (lifespan·라우터·컨테이너 전체) | **L3** `@pytest.mark.wiring` | ↓ |
| 3 | **포트/파일/시간/외부 경계**를 넘는가? | **L2** | **L1** |

> 판단이 개입하면 규칙이 아니다. 답이 갈리면 **질문이 잘못된 것**이므로 이 표를 고친다.

## 2. 등급 요약

| 등급 | 지키는 것 | 앱 부팅 | 파일 I/O | 마커 | 예산 | 문서 |
| :---: | --- | :---: | :---: | --- | ---: | --- |
| **L0** | 의존 방향 · 배치 · 목록 최신성 | ✕ | ✕ | (lint) | 0.5초 | [`01.L0-rules.md`](./01.L0-rules.md) |
| **L1** | 계약 · 스키마 · 어휘 | ✕ | ✕ | 없음 | 1초 | [`02.L1-contracts.md`](./02.L1-contracts.md) |
| **L2** | 포트 뒤의 행동 | ✕ | ○ (`tmp_path`) | 없음 | 2초 | [`03.L2-units.md`](./03.L2-units.md) |
| **L3** | 조립 · 부팅 · HTTP 계약 | ○ (세션 1회) | ○ | `wiring` | 5초 | [`04.L3-wiring.md`](./04.L3-wiring.md) |

**기본 실행(`pnpm test`)은 L1+L2 만 돈다.** L0 은 `pnpm lint`, L3 은 `pnpm test:all`.

---

## 3. 예산은 무엇을 위한 것인가

예산은 성능 목표가 아니라 **등급 이탈 탐지기**다.

| 증상 | 진짜 의미 |
| --- | --- |
| L1 이 1초를 넘음 | 어딘가에서 파일을 쓰거나 앱을 임포트했다 → **L2/L3 가 섞였다** |
| L2 가 2초를 넘음 | 외부 프로세스를 띄웠거나 실제 저장소를 쓴다 |
| L3 가 5초를 넘음 | 앱을 여러 번 부팅한다 → `api_client` 세션 픽스처를 안 썼다 |

> 2026-09-14 기준 전체 10.1초, 최장 테스트 0.40초다. **실행 시간 자체는 문제가 아니었다.**
> 예산은 "느려서 줄이자"가 아니라 **"등급이 섞였음을 알려주는 신호"** 로 쓴다.

## 4. 같은 사실을 두 등급에서 검증하지 않는다

| 검증하려는 것 | 옳은 등급 | 여기서 하면 안 되는 곳 |
| --- | :---: | --- |
| 토큰 변환이 무손실인가 | L1 | L3 (라우터 응답으로 확인) |
| 삭제가 연쇄되는가 | L2 | L3 (`DELETE` 요청으로 확인) |
| 부팅이 핸들러를 등록했는가 | L3 | L2 (등록 함수만 직접 호출) |
| 도메인 간 import 금지 | L0 | L2 (AST 순회) |

> **왜**: 같은 사실이 두 곳에서 깨지면 원인 범위를 좁힐 수 없다. 하나 고장에 둘이 빨개지면
> "어느 쪽이 진짜 원인인가"를 사람이 다시 판단해야 한다.

## 5. 마커 규약

```python
# 파일 전체가 L3 인 경우 (권장)
pytestmark = pytest.mark.wiring

# 한 테스트만 L3 인 경우
@pytest.mark.wiring
def test_...():
```

| 마커 | 뜻 | 기본 실행 |
| --- | --- | :---: |
| (없음) | L1 또는 L2 | **포함** |
| `wiring` | L3 배선 | 제외 |
| `external` | 외부 프로세스를 실제로 띄움 (예: `agy_status_bridge.py` 서브프로세스) | 제외 후보 |

`--strict-markers` 를 켜므로 **오타 난 마커는 에러**다. 이게 없으면 `wirring` 으로 잘못 쓴
테스트가 조용히 "마커 없는 테스트"가 되어 기본 실행에 섞여 들어간다.

---

## 6. 등급을 바꾸는 법

파일을 옮기지 않는다. **마커만 바꾼다.**

```python
# L2 였는데 앱 부팅이 필요해졌다면
pytestmark = pytest.mark.wiring     # 이 한 줄로 끝
```

파일 위치는 **검증 대상**이 정하고([`03.layout.md`](../03.layout.md)),
등급은 **실행 비용**이 정한다. 두 축을 섞지 않는다.
