# T3 — 소유권 이관 (packages 귀속)

- **상태**: ⬜ 대기
- **선행**: T0
- **해소하는 감사 항목**: [4-5](../audit/2026-09-14/audit_test_suite_baseline.md) (소유권 어긋남)

---

## 무엇을

`apps/api/tests` 에 살면서 실제로는 `packages/*` 를 검증하는 테스트를 제자리로 옮긴다.

---

## 왜

엔진 계약이 깨졌는데 신호가 앱에서 오면, **원인이 어느 층인지 매번 다시 판단**해야 한다.
`packages/*` 는 호스트 비의존 정본이다. 그 정본의 테스트가 호스트에 있으면,
패키지만 따로 쓰는 순간 검증 수단이 사라진다.

판정 기준: **"고장 나면 누가 고쳐야 하는가"** 쪽이 소유한다.

---

## 대상

전체 매핑: [`mapping/packages.md`](./mapping/packages.md)

| 현재 위치 | 테스트 | 옮길 곳 | 근거 |
| --- | ---: | --- | --- |
| `test_scaffold_multipage.py` | 1 | `packages/scaffold-engine/tests/` | `ScaffoldPipeline` 자체를 검증 |
| `test_llm_fallback.py` | 4 | `packages/agent-core/tests/` | `FallbackLlmHarness` 검증 |
| `test_provider_state.py` | 5 | `packages/agent-core/tests/` | `ProviderStateStore` 검증 |
| `test_google_structured_output.py` | 3 | `packages/agent-core/tests/` | `GoogleGenAiHarness` 요청 조립 검증 |
| `test_cli_availability.py` | 3 | `packages/agent-core/tests/` | `CliQuotaAvailability` 검증 |
| `test_observability_contract.py` 일부 | ~6 | `packages/agent-telemetry/tests/` | 어휘·사용량 계약 |
| `test_scaffold_observability.py` 일부 | ~3 | `packages/scaffold-engine/tests/` | 파이프라인이 스팬을 방출하는가 |
| `test_outline_observability.py` 일부 | ~1 | `packages/scaffold-engine/tests/` | 동일 |

**앱에 남는 것**: 어댑터가 엔진을 호출하는 부분, 계측 결과를 저장하는 부분.

## 판정이 애매한 경우

| 테스트 | 검증하는 것 | 소유 |
| --- | --- | --- |
| `EngineOutlineExtractAdapter` 가 스팬을 남기는가 | **어댑터** | 앱 |
| `OutlinePipeline` 이 스팬을 방출하는가 | **엔진** | 패키지 |
| 어댑터가 엔진 결과를 `RunCost` 로 변환하는가 | **어댑터** | 앱 |
| `SpanUsage` 왕복이 무손실인가 | **계약** | 패키지(agent-telemetry) |

> 한 테스트가 둘 다 보고 있으면 **쪼갠다.** 쪼갤 수 없으면 그것은 어댑터 테스트다
> (엔진은 어댑터 없이도 검증 가능해야 하므로).

## 절차

### 1. `packages/agent-telemetry/tests/` 신설

현재 이 패키지에는 테스트 디렉터리가 없다.

```bash
mkdir -p packages/agent-telemetry/tests
```

T0 에서 `pyproject.toml` 에 pytest 설정과 `package.json` 을 추가했는지 확인한다.

### 2. 한 파일씩 옮긴다

```bash
git mv apps/api/tests/test_llm_fallback.py packages/agent-core/tests/
```

`git mv` 를 쓴다. 이력이 이어져야 **"이 테스트가 왜 생겼는지"** 를 추적할 수 있다.

### 3. 임포트 경로 수정

```python
# Before (앱 경유)
from app.core.llm import FallbackLlmHarness

# After (패키지 직접)
from llm_driver import FallbackLlmHarness
```

> 앱 경유 임포트가 남아 있으면 **패키지가 앱에 의존**하게 되어 계약 위반이다.
> `import-linter` 의 `Agent Core is domain agnostic` 이 잡는다.

### 4. 부분 이관은 파일을 쪼개서

`test_observability_contract.py` 처럼 일부만 옮기는 경우:

1. 옮길 테스트를 새 파일로 **복사**한다 (주석 포함).
2. 새 위치에서 통과를 확인한다.
3. 원래 파일에서 **삭제**한다.
4. 두 위치에서 전체 게이트를 돌린다.

복사 → 확인 → 삭제 순서를 지킨다. 잘라내기로 하면 중간 상태에서 검증이 사라진다.

## 완료 판정

```bash
# 1. 패키지 테스트가 자동 실행된다
pnpm test
#    기대: agent-core, scaffold-engine, agent-telemetry 전부 실행

# 2. 패키지가 앱을 임포트하지 않는다
cd apps/api && venv/Scripts/lint-imports.exe
#    기대: Contracts: 11 kept, 0 broken.

# 3. 패키지만 따로 돌려도 통과한다 — 소유권의 진짜 시험
cd packages/agent-core && ../../apps/api/venv/Scripts/python.exe -m pytest -q
cd packages/scaffold-engine && ../../apps/api/venv/Scripts/python.exe -m pytest -q

# 4. 앱 테스트 수가 예상만큼 줄었다
cd apps/api && venv/Scripts/python.exe -m pytest -m "" --collect-only -q | tail -1
```

§3 의 "패키지만 따로 돌려도 통과"가 **이 단계의 본질적 판정**이다.
앱 없이 돌지 않는다면 소유권이 아직 틀린 것이다.

## 되돌리는 법

```bash
git mv packages/agent-core/tests/test_llm_fallback.py apps/api/tests/
# 임포트 경로 되돌리기
```

파일 단위로 옮겼으므로 파일 단위로 되돌린다.

## 기대 수치

| | Before | After |
| --- | --- | --- |
| 자동 실행 패키지 테스트 | 14 (수동) | **~35** |
| 앱 테스트 | ~110 | ~85 |
| 패키지 단독 실행 | 일부만 가능 | **전부 가능** |
| turbo 캐시 효과 | 앱 수정 시 전체 | **패키지 수정 시 그 패키지만** |

> 마지막 줄이 실제 절감이다. 엔진을 고쳤을 때 앱 테스트 85개를 다시 돌릴 이유가 없다.

## 주의

| 함정 | 대응 |
| --- | --- |
| `cp` 로 옮긴다 | `git mv` 를 쓴다. 이력이 끊기면 사고 기록의 맥락이 사라진다 |
| 앱 경유 임포트를 남긴다 | 패키지가 앱에 의존하게 된다. 계약이 잡지만 먼저 고친다 |
| 어댑터 테스트까지 옮긴다 | 어댑터는 앱의 것이다. 판정표를 적용한다 |
| 부분 이관을 잘라내기로 | 복사 → 확인 → 삭제 |
