# 시각적 레퍼런스 세그먼트 조작 (Visual Canvas Segmentation)

## 설명
텍스트나 폼(Form) 입력 방식이 아닌, 사용자가 업로드한 원본 레퍼런스(PDF, PPT, 웹 이미지 등) 위에 **직접 초록색 점선 박스(Bounding Box)를 치고, 그 크기를 줄이거나 이동시키며 문서의 구조(Segment)를 시각적으로 추출해 내는 인터랙티브 캔버스 기능**입니다.

## 핵심 가치
1. **직관적인 템플릿(지문) 추출:** 사용자는 "이 문서는 서론이 30%야"라고 말로 설명할 필요 없이, 단순히 이미지 위에 박스를 치는 것만으로 에이전트에게 "여기가 서론이야"라는 구조적 메타데이터(좌표와 넓이)를 정확히 전달할 수 있습니다.
2. **다양한 포맷 대응:** 엑셀, 워드, 파워포인트 등 포맷에 구애받지 않고 시각적 렌더링(이미지화)만 가능하다면 동일한 캔버스 UI 위에서 통일된 방식으로 세그먼트를 매핑할 수 있습니다.

## 핵심 프론트엔드 스펙 (Tech Spec)
기존 DOM(`<div>`) 기반의 한계를 극복하기 위해 실험했던 Canvas 방식을 폐기하고, 최종적으로 유연성과 노드 기반 확장이 용이한 **DOM 기반 노드 에디터 엔진**을 채택합니다.

* **1순위 (최종 확정 스펙): `React Flow` + `Tiptap`**
  - **React Flow**: 레퍼런스를 캔버스에 깔고, 그 위에 시각적인 세그먼트 박스(Node)를 띄워 부드러운 박스 조작 감각과 줌/팬(Zoom/Pan) 기능을 제공합니다. 각 박스의 좌표와 크기를 추출해 스캐폴드 데이터로 활용합니다.
  - **Tiptap**: 각 세그먼트 박스 내부의 텍스트 편집 및 블록 기반 마스킹 조작을 담당하는 Headless 에디터로 연동됩니다.

* **2순위 (폐기된 스펙): `React-Konva` 등 HTML5 Canvas 기반**
  - AI 비전 라벨링 목적의 Bounding Box에는 유리하나, 내부 텍스트 에디팅(Tiptap)과의 결합이 까다로워 현재 브랜치에서는 사용하지 않습니다.
