# 컨텍스트 기반 부분 생성 (Context-Aware Inpainting)

## 설명
마스크가 씌워진 구역에 대해 사용자가 "총예산 5천만 원에 맞춰서 표를 작성해 줘"라고 프롬프트를 입력하면, 에이전트는 **마스크 외부의 문서 흐름(문맥)을 참조하면서도 오직 마스크 내부의 내용만** 새로 생성하여 채워 넣습니다.

## 핵심 가치
빈 템플릿의 각 구역을 돌아다니며 에이전트에게 핑퐁 지시를 내리는 것만으로, 복잡한 프로젝트성 문서나 보고서를 레고 블록 조립하듯 순식간에 완성할 수 있습니다.
