# 점진적 구체화 워크플로 (Progressive Elaboration Workflow)

## 설명
초기의 '거친 아이디어(Rough Concept)'에서 출발하여, **"다각도 후보군 제시 ➔ 후보 선택 ➔ 상세 목차 전개 ➔ 최종 작업 캔버스 전환"**의 순서로 점진적으로 해상도를 높여나가는 연속적인 파이프라인 시나리오입니다. 기획자는 처음부터 백지에 완벽한 목차를 짜야 하는 부담감을 덜고, 에이전트가 제안하는 뼈대를 깎아나가며(Sculpting) 문서를 완성할 수 있습니다.

## 워크플로 4단계 (시나리오 기반)

1. **Initiation (초기 컨셉 및 제약 조건 설정)**
   - 기획자는 '메인 컨셉'을 가볍게 작성하고, 96 파이프라인에서 추출된 '리소스 폴더'를 드래그 앤 드롭으로 던져 넣습니다.
   - 💡 **핵심 제어:** `[반드시 리소스로만 아웃라인 생성하기 0~100%]`와 같은 슬라이더를 통해 에이전트의 창의성과 리소스 의존도를 인간이 직접 각을 잡아줍니다.

2. **Simulation (다각도 아웃라인 후보군 제시)**
   - 에이전트가 투입된 리소스와 템플릿 룰을 바탕으로, 각기 다른 방향성(예: 실무자용, 관리자용, 역발상용 등)을 가진 3~4개의 '아웃라인 후보(안건)'를 제시합니다.
   - 마음에 들지 않으면 피드백을 입력하고 다시 뽑아냅니다(재생성).

3. **Detailing (후보 선택 및 상세화 전개)**
   - 기획자가 하나의 후보를 선택(Click)하면, 거시적인 뼈대가 \[부] -> \[장] -> \[절] 단위의 '상세 아웃라인'으로 쫙 펼쳐집니다.
   - 이때 앞서 정의한 **[Node-Level Resource Manager]**와 **[Flexible Post-it Mapping]** UI가 활성화되어, 단락별로 어떤 카드가 매핑되었는지 확인하고 떼었다 붙였다 교정합니다.

4. **Canvas Transition (실제 작업 보드로 전환)**
   - 뼈대와 리소스 매핑이 확정되면, 텍스트 형태의 아웃라인이 실제 텍스트/데이터를 채워 넣을 수 있는 '격자형(Grid) 작업 캔버스'로 부드럽게 전환됩니다.
   - 우측에는 프로젝트 목표, 작업 기준, 참조 레퍼런스가 패널로 고정(Pinned)되어 작업 내내 가이드 역할을 합니다.

## 핵심 가치
- **Cold Start 극복:** "뭐부터 써야 하지?"라는 막막함을 에이전트의 '후보군 제시'로 돌파합니다.
- **인간과 AI의 핑퐁 (Human-in-the-loop):** '에이전트 제안 -> 인간 선택/수정 -> 에이전트 상세화 -> 인간 튜닝'이라는 가장 이상적인 하네스 엔지니어링의 리듬을 UI 흐름으로 강제합니다.
