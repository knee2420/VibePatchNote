# 🚀 Stack Combo 3: React-Grid-Layout + Editor.js (대시보드형 그리드 빌더)

## 📌 아키텍처 개요
**"xTiles처럼 캔버스를 격자(Grid)로 분할하여 깔끔한 타일 형태로 관리한다"**
* **공간 제어 (그리드 스냅):** `React-Grid-Layout` (대시보드 형태의 위젯 배치 라이브러리)
* **텍스트 제어 (JSON 블록):** `Editor.js` (출력물이 깔끔한 JSON으로 나오는 블록 에디터)

## 💡 구현 방식
무한 캔버스 대신, 격자(Grid)가 쳐진 칠판을 제공합니다. 사용자는 아웃라인이나 지식 카드를 '타일(Tile)' 형태로 격자에 맞춰 착착 배치합니다.
각각의 타일 안에는 `Editor.js`가 인스턴스로 돌아가고 있어서, 타일을 클릭하면 바로 글을 쓸 수 있습니다.

## 🎯 장단점 분석 (vs xTiles 벤치마킹)
* **👍 장점 (구조적 깔끔함):** 무한 캔버스는 자유롭지만 지저분해지기 쉽습니다. 그리드 시스템을 쓰면 템플릿(서론, 본론 등)이 깔끔한 블록 단위로 딱딱 맞아떨어져, '탑다운 아웃라인 에디터'를 시각화하기에 매우 좋습니다. JSON 기반이라 AI와 데이터(마스킹)를 주고받기 편합니다.
* **👎 단점 (자유도 제약):** 화이트보드처럼 노드끼리 선(Edge)을 연결하거나, 포스트잇을 삐딱하게 겹쳐 붙이는 등의 유연한 표현은 불가능합니다. 오직 네모 반듯한 타일 형태로만 작업해야 합니다.
