# 🚀 Stack Combo 2: Slate.js + dnd-kit (문서 중심 블록 에디터)

## 📌 아키텍처 개요
**"무한 캔버스를 포기하고, 노션(Notion) 같은 극한의 문서 안정성을 취한다"**
* **텍스트/블록 제어:** `Slate.js` (가장 자유도가 높은 에디터 프레임워크)
* **공간 제어 (드래그 앤 드롭):** `dnd-kit` (가볍고 강력한 리액트 DND 라이브러리)

## 💡 구현 방식
2D 무한 캔버스라는 공간적 자유도를 포기합니다. 대신 노션이나 구글 문서처럼 위에서 아래로 흐르는 수직형(Vertical) 문서 구조를 기본으로 합니다. 
아웃라인(목차)이나 지식 카드(포스트잇)는 화면 우측의 **사이드 패널(Side Panel)**이나 문서 내의 **인라인 블록** 형태로 존재하며, `dnd-kit`을 이용해 카드를 본문 안으로 끌어다(Drag & Drop) 놓는 방식으로 매핑합니다.

## 🎯 장단점 분석
* **👍 장점 (문서로서의 안정성):** 무한 캔버스 좌표계(X, Y, Zoom)를 계산할 필요가 없으므로 개발 난이도가 대폭 하락합니다. 문서 중심이므로 '부분 마스킹 후 재생성', '하이브리드 텍스트 편집'을 구현하기가 가장 쉽고 깔끔합니다.
* **👎 단점 (시각적 제약):** '포스트잇을 캔버스 여기저기에 자유롭게 붙이며 시각적 영감을 얻는' 기획적 재미(미로 같은 느낌)가 사라지고, 딱딱한 문서 작성 툴로 느껴질 수 있습니다.
