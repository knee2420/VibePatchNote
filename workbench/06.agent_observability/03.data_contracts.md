## 1. 데이터 모델링 핵심 개념 (Conceptual Entity Diagram)

옵저빌리티 시스템이 관리하는 데이터는 크게 **4개 계층(Trace/Span ➔ Fallback Attempt ➔ Intermediate State ➔ Human Interaction)**으로 구성된다.

```text
┌────────────────────────────────────────────────────────────────────────┐
│ 1. TraceRecord (run_id) : 파이프라인 1회 전체 실행 세션                  │
│    ├── root_span_id, trigger_source, session_status, total_metrics... │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ 1 : N (계층 트리: dotted_order)
┌───────────────────────────────────▼────────────────────────────────────┐
│ 2. SpanRecord : 개별 작업 실행 단위 (Pipeline / Chain / LLM / Tool)    │
│    ├── span_id, parent_span_id, dotted_order, span_type, status       │
│    ├── inputs (JSON) / outputs (JSON) / error                          │
│    ├── metadata : CLI/API/환경 메타데이터 (코딩 에이전트 규약)          │
│    └── usage : 토큰(입력/출력/추론), 소요 시간(ms), 예상 비용           │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ 1 : N (LLM Fallback 발생 시)
┌───────────────────────────────────▼────────────────────────────────────┐
│ 3. ModelAttemptRecord : 모델 호출 단위 시도 (1차, 2차, 3차...)         │
│    ├── attempt_index, provider (agy_cli | google_api | local_serving) │
│    ├── model_name, request_payload, raw_response, stderr              │
│    └── outcome : SUCCESS | FAILED (실패 사유: 429, Timeout, Crash...)  │
└────────────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────────────┐
│ 4. StageSnapshotRecord : 파이프라인 단계별 중간 도메인 상태            │
│    ├── stage_id (context_build | prompt_assembly | parsing | binding) │
│    ├── domain_payload : 각 단계의 정형 산출물 (Pydantic 역직렬화 가능)  │
│    └── diff_summary : 이전 단계 대비 변경 내역                         │
└────────────────────────────────────────────────────────────────────────┘
```

## 2. Pydantic v2 백엔드 스키마 정의 (Python SSOT)

백엔드(`apps/api`, `packages/scaffold-engine`)에서 런타임 데이터를 직렬화/역직렬화할 때 사용할 표준 스키마 모델이다.

### 2.1 공통 열거형 (Enums)

```python
from enum import Enum

class SpanType(str, Enum):
    PIPELINE = "pipeline"     # 최상위 파이프라인 실행
    CHAIN = "chain"           # 순차 처리 복합 단계 (예: Fallback 오케스트레이터, 컨텍스트 빌더)
    LLM = "llm"               # 실제 LLM 추론 호출 (CLI subprocess 또는 REST API)
    TOOL = "tool"             # 외부 CLI 명령어/스크립트/도구 호출
    PARSER = "parser"         # 구조화 JSON 파싱 및 스키마 검증기

class SpanStatus(str, Enum):
    PENDING = "pending"
    RUNNING = "running"
    SUCCESS = "success"
    FAILED = "failed"
    SKIPPED = "skipped"

class ExecutionProtocol(str, Enum):
    CLI_SUBPROCESS = "cli_subprocess"   # OS 프로세스 stdin/stdout (agy, gpt-cli, claude-cli)
    DIRECT_REST_API = "direct_rest_api" # HTTP 공식 SDK (Google Gemini, OpenAI, Anthropic)
    LOCAL_SERVING = "local_serving"     # vLLM, Ollama, 로컬 소켓/포트

class FailureReason(str, Enum):
    TIMEOUT = "timeout"
    RATE_LIMIT_429 = "rate_limit_429"
    PROCESS_CRASH = "process_crash"
    AUTH_ERROR = "auth_error"
    SCHEMA_VALIDATION_ERROR = "schema_validation_error"
    UNKNOWN = "unknown"
```

### 2.2 메타데이터 및 사용량 모델 (Metadata & Usage)

```python
from typing import Optional, List, Dict, Any
from pydantic import BaseModel, Field

class SpanUsage(BaseModel):
    """토큰 소모량 및 소요 시간 집계"""
    prompt_tokens: int = Field(0, description="입력 프롬프트 토큰 수")
    completion_tokens: int = Field(0, description="출력 생성 토큰 수")
    reasoning_tokens: Optional[int] = Field(None, description="사고/추론 토큰 수 (지원 모델 한정)")
    total_tokens: int = Field(0, description="총 토큰 수")
    latency_ms: float = Field(0.0, description="소요 시간 (밀리초)")
    estimated_cost_usd: Optional[float] = Field(None, description="예상 비용 (달러)")

class SpanMetadata(BaseModel):
    """코딩 에이전트 및 CLI 환경 메타데이터"""
    agent_runtime: str = Field(..., description="런타임 식별자 (예: agy-cli 2.0, google-genai-sdk)")
    execution_protocol: ExecutionProtocol = Field(..., description="실행 프로토콜 분류")
    provider: str = Field(..., description="하네스 공급자 (agy_cli, google_api, local_serving)")
    model_name: str = Field(..., description="실행 모델명 (gemini-3.5-flash, gemma-4-31b 등)")
    thread_id: Optional[str] = Field(None, description="문서 또는 세션 ID")
    git_branch: Optional[str] = Field(None, description="현재 활성 Git 브랜치")
    git_commit_sha: Optional[str] = Field(None, description="현재 Git 커밋 해시")
    working_directory: Optional[str] = Field(None, description="실행 작업 디렉터리")
    
    # CLI 서브프로세스 전용 필드
    cli_command: Optional[List[str]] = Field(None, description="실행된 CLI 인자 배열")
    exit_code: Optional[int] = Field(None, description="프로세스 종료 코드 (0: 성공)")

class SpanError(BaseModel):
    """장애 발생 시 에러 상세 구조"""
    code: str = Field(..., description="에러 식별 코드 (예: CLI_TIMEOUT, HTTP_429)")
    message: str = Field(..., description="사용자 친화적 에러 메시지")
    failure_reason: FailureReason = Field(FailureReason.UNKNOWN, description="장애 원인 분류")
    stack_trace: Optional[str] = Field(None, description="파이썬 예외 트레이스백 원문")
    stderr: Optional[str] = Field(None, description="CLI stderr 표준 에러 버퍼 원문")
```

### 2.3 핵심 Span & Trace 레코드 (Span & Trace Records)

```python
from datetime import datetime

class SpanRecord(BaseModel):
    """단일 실행 스팬 모델 (LangSmith Run 호환)"""
    span_id: str = Field(..., description="고유 스팬 식별자 (UUIDv7)")
    trace_id: str = Field(..., description="최상위 파이프라인 실행 ID (run_id)")
    parent_span_id: Optional[str] = Field(None, description="직속 부모 스팬 ID")
    dotted_order: str = Field(..., description="계층 정렬 키 (<시작시간>Z<루트ID>.<시작시간>Z<자식ID>)")
    name: str = Field(..., description="작업 논리명 (예: outline_pipeline, build_context)")
    span_type: SpanType = Field(..., description="스팬 유형")
    status: SpanStatus = Field(SpanStatus.PENDING, description="스팬 상태")
    
    start_time: datetime = Field(..., description="시작 시각 (UTC)")
    end_time: Optional[datetime] = Field(None, description="종료 시각 (UTC)")
    
    inputs: Dict[str, Any] = Field(default_factory=dict, description="입력 매개변수 JSON")
    outputs: Optional[Dict[str, Any]] = Field(None, description="산출 결과 JSON")
    error: Optional[SpanError] = Field(None, description="실패 시 에러 정보")
    
    metadata: SpanMetadata = Field(..., description="실행 환경 및 런타임 메타데이터")
    usage: SpanUsage = Field(default_factory=SpanUsage, description="토큰 및 성능 사용량")

class TraceRecord(BaseModel):
    """최상위 파이프라인 세션 요약 모델"""
    run_id: str = Field(..., description="Trace 고유 식별자 (루트 span_id와 동일)")
    pipeline_name: str = Field(..., description="파이프라인 명칭 (OutlinePipeline 등)")
    trigger_source: str = Field("manual", description="실행 트리거 (ui_button, test_runner, api)")
    status: SpanStatus = Field(SpanStatus.PENDING, description="전체 세션 상태")
    start_time: datetime = Field(..., description="파이프라인 시작 시각")
    end_time: Optional[datetime] = Field(None, description="파이프라인 종료 시각")
    total_latency_ms: float = Field(0.0, description="총 세션 소요 시간")
    total_usage: SpanUsage = Field(default_factory=SpanUsage, description="세션 전체 합산 토큰/비용")
    root_span: Optional[SpanRecord] = Field(None, description="최상위 루트 스팬 객체")
```

### 2.4 Model Attempt & Fallback 모델 (Model Attempt Records)

`llm-gateway-fallbacks.md`를 벤치마킹하여, 하나의 상위 LLM 요청에 대해 발생한 여러 시도들을 추적한다.

```python
class ModelAttemptRecord(BaseModel):
    """단일 LLM 호출 시도 기록 (Fallback 체인 내부 요소)"""
    attempt_index: int = Field(..., description="시도 순번 (1부터 시작)")
    provider: str = Field(..., description="공급자 (agy_cli, google_api, local_serving)")
    model_name: str = Field(..., description="호출 모델명")
    execution_protocol: ExecutionProtocol = Field(..., description="실행 프로토콜")
    
    status: SpanStatus = Field(..., description="시도 결과 상태")
    latency_ms: float = Field(..., description="해당 시도 소요 시간")
    
    request_prompt_snippet: str = Field(..., description="전송된 프롬프트 앞부분 요약")
    raw_response: Optional[str] = Field(None, description="모델이 반환한 원문 텍스트")
    error: Optional[SpanError] = Field(None, description="실패 시 에러 상세")
    
    usage: SpanUsage = Field(default_factory=SpanUsage, description="토큰 사용량")

class FallbackChainSummary(BaseModel):
    """복수 시도에 대한 집계 컨테이너"""
    primary_provider: str = Field(..., description="1순위 지정 공급자")
    fallback_providers: List[str] = Field(default_factory=list, description="후순위 예비 공급자 목록")
    total_attempts: int = Field(1, description="실제 수행된 총 시도 횟수")
    successful_attempt_index: Optional[int] = Field(None, description="최종 성공한 시도 인덱스")
    attempts: List[ModelAttemptRecord] = Field(default_factory=list, description="시도 상세 목록")
```

### 2.5 단계별 중간 상태 스냅샷 모델 (Intermediate State Snapshots)

파이프라인의 5대 핵심 단계별 런타임 도메인 데이터를 캡처하는 모델이다.

```python
class ContextBuildPayload(BaseModel):
    """Stage 1: 문서 컨텍스트 빌드 결과"""
    source_filename: str
    source_file_size_bytes: int
    source_sha256: str
    page_count: int
    extracted_word_count: int
    bounding_box_count: int
    context_text_snippet: str
    media_asset_count: int

class PromptAssemblyPayload(BaseModel):
    """Stage 2: 프롬프트 구성 모듈 역분해 결과"""
    system_constitution_text: str
    system_constitution_tokens: int
    component_taxonomy_text: str
    component_taxonomy_tokens: int
    dynamic_context_tokens: int
    output_schema_tokens: int
    total_prompt_tokens: int
    assembled_prompt_full: str

class StructuredParsingPayload(BaseModel):
    """Stage 4: 아웃라인 파싱 및 보정 결과"""
    is_valid_json: bool
    schema_validation_passed: bool
    total_elements_extracted: int
    tables_count: int
    key_value_blocks_count: int
    repaired_bounding_boxes_count: int
    parsed_outline_tree: Dict[str, Any]

class EditorBindingPayload(BaseModel):
    """Stage 5: Tiptap 에디터 바인딩 결과"""
    tiptap_json_schema_valid: bool
    rendered_tiptap_html: str
    total_wireframe_nodes: int
    unbound_slots_count: int

class StageSnapshotRecord(BaseModel):
    """특정 단계 스냅샷 래퍼"""
    stage_id: str = Field(..., description="context_build | prompt_assembly | parsing | binding")
    stage_name: str = Field(..., description="사용자 친화적 단계명")
    timestamp: datetime = Field(default_factory=datetime.utcnow)
    payload: Dict[str, Any] = Field(..., description="해당 단계별 정형 데이터 딕셔너리")
```

## 5. 관리 및 사용 원칙 (Governance & Usage Rules)

1. **스키마 변경 헌법**:
   - `SpanRecord`의 핵심 필드(`span_id`, `trace_id`, `dotted_order`, `metadata`)는 하위 호환성을 위해 절대 필드명을 변경하거나 삭제하지 않는다.
   - 새로운 메타데이터나 분석 필드가 필요할 때는 `metadata` 딕셔너리의 확장 키로 수용한다.
2. **단방향 불변성 (Immutability)**:
   - 한 번 기록된 Span과 Event는 덮어쓰거나 변경할 수 없다. Fallback 재시도 역시 기존 Span을 수정하는 것이 아니라 새로운 `Attempt` Span을 생성하여 연결한다.
3. **타입 안전성 게이트**:
   - 백엔드는 Pydantic v2 모델의 `.model_dump_json()`, 프론트엔드는 TypeScript 인터페이스를 통해 런타임 직렬화 안전성을 상시 보장한다.
