# 다중 앵글 기반 아웃라인 시뮬레이션 및 매핑 (Multi-Angle Outline Simulation)

## 설명
본격적인 본문 생성에 들어가기 전, 기획자와 에이전트가 함께 목차(Outline)를 아이데이션하는 단계입니다. 기획자가 타겟과 메시지 등 다양한 '컨셉(Angle)'을 던지면, 에이전트는 동일한 지식 카드(Resource) 풀을 활용하더라도 **'실전 중심(안건 2)', '역발상 중심(안건 3)', '비유 중심(안건 4)' 등 완전히 다른 구조의 아웃라인 버전을 여러 개 시뮬레이션하여 제안**합니다. 이때 각 챕터마다 어떤 지식 카드(`출처: C-XX-XX`)가 매핑될지 시각적으로 명시해 줍니다.

## 핵심 가치
문서의 뼈대를 세울 때 기획자에게 압도적인 유연성과 제어권을 부여합니다. 
1. **양방향 설계 지원:** 기초 자료(Resource)를 바탕으로 아웃라인을 뽑아낼 수도 있고(Bottom-up), 거꾸로 아웃라인 뼈대를 먼저 세운 뒤 에이전트에게 알맞은 자료를 찾아 매핑하라고 지시할 수도 있습니다(Top-down).
2. **사전 진단:** 여러 버전의 아웃라인 시뮬레이션을 비교하면서, "이 앵글로 가면 3장 내용에 매핑할 기초 자료가 부족하겠구나"를 미리 파악하고 기획을 수정할 수 있는 완벽한 사전 검증(Ideation) 환경을 제공합니다.
