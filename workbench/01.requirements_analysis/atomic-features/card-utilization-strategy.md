# 레퍼런스 활용 방식 설정 (Utilization Strategy Selection)

## 설명
분석된 레퍼런스를 새 프로젝트에서 구체적으로 **어떻게 써먹을지** 사용자가 지정하는 기능입니다.
- **형식 껍데기만 빌리기:** 형식만 참고해 완전히 다른 주제로 작성
- **내용 마이그레이션:** 내가 가진 기존 원고를 이 레퍼런스의 폼(구조)에 맞춰서 변환
- **톤앤매너 모방:** 표 형식은 버리고, 문서의 말투와 구성 리듬만 참고

## 핵심 가치
"이 문서를 참고해 줘"라는 뭉뚱그린 지시가 아니라, **'어떤 속성(형식, 내용, 말투)을 상속받을 것인가'**를 명확히 정의함으로써, 에이전트가 엉뚱한 결과물을 내놓는 할루시네이션(환각)을 완벽하게 통제합니다.
