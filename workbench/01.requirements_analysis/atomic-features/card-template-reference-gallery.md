# 템플릿 기반 다중 레퍼런스 뷰어 (Template-Reference Gallery Viewer)

## 설명
템플릿을 선택했을 때 단순한 '출처 링크(텍스트)'만 제공하는 것이 아닙니다. 하나의 형식(Format/Template)에 동일한 구조를 띠는 **여러 개의 원본 레퍼런스(Reference)가 1:N(다대다/일대다) 관계로 매핑**되어 있어, 템플릿 선택 시 해당 양식을 사용한 실제 원본 문서들을 시각적인 갤러리 형태로 즉시 함께 보여줍니다.

## 핵심 가치
사용자는 '빈 템플릿'만 덩그러니 보고 막막해할 필요가 없습니다. 이 템플릿(작업틀)이 실제 실무에서 어떻게 채워져 훌륭한 결과물(Ref 1, Ref 2, Ref 3...)로 완성되었는지, 그 **살아있는 모범 사례(Best Practices)들을 바로 옆에 띄워두고 직접 보며 작업**할 수 있습니다. 템플릿 자체가 거대한 '레퍼런스 카탈로그' 역할을 하게 됩니다.
