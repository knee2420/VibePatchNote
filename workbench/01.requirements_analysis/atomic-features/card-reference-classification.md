# 레퍼런스 유형 자동 식별 및 보정 (Reference Classification)

## 설명
레퍼런스 문서가 업로드되면, 시스템(MangoDoc)이 해당 문서의 형식을 분석하여 알맞은 템플릿 유형(예: 멀티트랙 시퀀스, 러닝타임 예산표, 속성 테이블 등)을 자동으로 제안합니다. 사용자는 AI가 제안한 유형이 맞는지 확인하고, 필요시 '기타'를 선택해 직접 용도를 부연 설명할 수 있습니다.

## 핵심 가치
문서의 겉보기 텍스트가 아닌 '문서의 목적성(유형)'을 시스템이 먼저 파악함으로써, 향후 에이전트가 문서를 재생성할 때 해당 유형에 최적화된 프롬프트와 레이아웃(캔버스)을 준비할 수 있도록 돕습니다.
