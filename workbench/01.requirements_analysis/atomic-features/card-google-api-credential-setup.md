# Google API 자격증명 설정

## 설명

사용자는 설정 화면에서 Google API 키를 등록, 연결 테스트, 삭제할 수 있다. 키 원문은 OS 보안 저장소에만 저장하며 API와 UI는 설정 여부만 조회한다.

## 핵심 가치

백업 실행 수단을 사용자가 통제하면서도 키를 작업공간·로그·브라우저 저장소에 노출하지 않는다.
