# 추출된 트리의 모듈화 (Modular Tree Builder)

## 설명
원본 문서에서 추출 및 재조정된 세그먼트들은 우측 패널에 윈도우 폴더 트리(예: `[F1] -> [M1]`)처럼 구조화되어 나타나며, 사용자는 이 모듈들을 조립하거나 편집하여 새로운 문서의 아웃라인을 짤 수 있습니다.

## 핵심 가치
추출된 세그먼트는 단순한 텍스트 쪼가리가 아니라, 에이전트가 이해할 수 있는 완벽한 재료(Resource)가 되어 새로운 문서 생성 파이프라인의 핵심 인풋으로 사용됩니다.
