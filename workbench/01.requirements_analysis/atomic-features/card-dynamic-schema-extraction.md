# 동적 스키마 및 계층 구조 추출 (Dynamic Schema Extraction)

## 설명
업로드된 레퍼런스가 유튜브 스크립트이든, 사업계획서이든, 제안서이든 특정 도메인에 국한되지 않고, AI가 **해당 문서만의 고유한 논리적 계층(Macro -> Micro)과 데이터 스키마를 동적으로 추론**하여 스캐폴딩을 분해합니다.
(예: 스크립트라면 '주제->행', 사업계획서라면 '시장분석->타겟/규모', 기획서라면 '배경->목적->기대효과' 등으로 구조를 파악)

## 핵심 가치
사전에 정의된 템플릿(하드코딩된 양식)에 문서를 끼워 맞추는 것이 아니라, **어떤 형태의 실무 문서가 들어오더라도 그 문서의 DNA(구조적 규칙)를 시스템이 스스로 학습하여 범용적인 파싱 파이프라인을 제공**합니다.
