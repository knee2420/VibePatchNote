# 도메인 특화 속성 태깅 (Domain-Specific Property Tagging)

## 설명
동적으로 분해된 미시 블록(세그먼트)들에 대해, 해당 문서 도메인에서 요구하는 **맞춤형 역할(Semantic Role)과 속성을 1:1로 매핑 및 태깅**합니다.
(예: 스크립트 도메인에서는 'Time', 'Narration', 'Video'로 태깅. 제안서 도메인에서는 '예산', '일정', '산출물'로 태깅)

## 핵심 가치
추출된 텍스트 조각들이 에이전트 워크플로우에 투입될 때, 각 조각이 어떤 '컨텍스트'를 가지고 있는지 시스템이 완벽하게 이해하게 됩니다. 이는 단순한 텍스트 파싱을 넘어 **모든 종류의 기획 문서를 구조화된 데이터베이스(Entity)로 변환**하는 핵심 엔진입니다.
