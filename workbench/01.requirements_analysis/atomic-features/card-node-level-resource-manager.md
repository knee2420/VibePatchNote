# 아웃라인 노드별 리소스 매니저 (Node-Level Resource Manager)

## 설명
아웃라인(목차)의 특정 챕터나 단락(Node)을 클릭하면, 우측 패널에 **해당 단락을 생성하는 데 사용될 '기초 지식 카드(Resource)'들이 시각적으로 매핑되어 나타나는 UI 컴포넌트**입니다. 기획자는 텍스트로 된 목차를 보면서, 동시에 우측 패널에서 각 목차에 어떤 카드들이 장착되어 있는지 직관적으로 관리할 수 있습니다.

## 핵심 가치
1. **정밀한 데이터 통제 (Micromanagement):** 에이전트에게 전체 자료를 한 번에 던져주고 알아서 분배하라고 하는 것이 아니라, "1부 1장에는 이 A카드와 B카드만 사용하고, 2부에는 C카드만 사용해"라는 식으로 **단락(Node) 단위의 엄격한 데이터 차출 범위를 강제**할 수 있습니다.
2. **시각적 결핍 진단 (Visual Gap Analysis):** 우측 패널의 리소스 슬롯이 비어있는 챕터를 발견하면(예: `[ + ]` 빈 슬롯만 있는 경우), 기획자는 즉시 "아, 이 챕터는 뼈대만 있고 내용이 비어있구나"라고 시각적으로 인지하고, 에이전트에게 해당 챕터를 채울 리소스를 검색해 오거나 새로 작성하라고 '발주서'를 발행할 수 있습니다.
