# 고정된 작업 기준 패널 (Pinned Context Panel)

## 설명
작업 화면 우측에 **[프로젝트 목표], [선택한 템플릿 양식], [참조 레퍼런스 원본]**이 항상 고정(Pinned)되어 있는 사이드 패널을 제공합니다. 이는 문서 작업이 끝날 때까지 닫히지 않고 인간과 에이전트 양쪽 모두의 시야에 유지됩니다.

## 핵심 가치
작업을 하다 보면 초기의 기획 의도를 잃고 산으로 가는 경우가 많습니다. 우측의 고정 패널은 프로젝트의 '북극성(North Star)' 역할을 하여, **사용자가 각을 잡거나(Steering) 에이전트가 글을 쓸 때 절대 원래의 KPI와 템플릿 규격에서 벗어나지 않도록 실시간 나침반 역할**을 해줍니다.
