# 하이브리드 편집 시스템 (Hybrid Editing System)

## 설명
생성된 결과물을 수정할 때, 사용자는 두 가지 방식을 섞어서 매우 편하게 작업할 수 있습니다. 
1. **Direct 편집**: 사용자가 에디터에 직접 개입해 텍스트를 고치거나 지우는 전통적인 방식
2. **Agent 편집**: 특정 블록을 드래그하거나 지정한 뒤 "이 부분 톤앤매너 수정해줘", "분량 줄여줘"라며 에이전트에게 부분 수정을 지시하는 방식

## 핵심 가치
"수정이나 편집이 편해야 한다"는 기획 의도를 완벽히 구현합니다. 100% 수동으로 고치는 것도 피곤하고, 100% AI에게 다시 써달라고 하는 것도 답답한 실무자의 페인포인트(Pain-point)를 해결하여, **기획자와 AI가 한 문서를 두고 탁구 치듯(티키타카) 완성해 나가는 궁극의 편집 UX**를 제공합니다.
