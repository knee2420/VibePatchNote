# 이 섹션은

Kibo UI 컴포넌트들을 복합적으로 조합해 만든 **28개 페이지 빌딩 블록(Blocks)**을 모아둔 섹션이다.
랜딩 페이지, 대시보드 섹션, 프로덕트 소개 등을 단번에 구축할 때 필요한 고수준 프리셋을 제공한다.
