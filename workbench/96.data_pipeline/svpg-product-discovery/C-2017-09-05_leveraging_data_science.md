# summary
데이터 사이언스는 출시 후 성과를 리포팅하는 보고서 작성용 조직이 아니다. **디스커버리 초기부터 데이터 사이언티스트가 결합하여 가설 수립, 탐색적 데이터 분석(EDA), 머신러닝 기반 가치 창출 가능성을 실시간으로 타진**해야 한다.
