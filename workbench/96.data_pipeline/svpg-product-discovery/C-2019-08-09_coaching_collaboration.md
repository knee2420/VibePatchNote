# summary
많은 조직이 회의실에서 각자의 의견을 절충하는 것을 협업이라고 착각한다. **진정한 협업은 타협이나 다수결이 아니라, PM의 비즈니스 지식, 디자이너의 인터랙션 통찰, 엔지니어의 기술적 가능성이 충돌하여 아무도 혼자서는 생각할 수 없었던 최적의 솔루션을 발견하는 것**이다.
