# summary
문제를 완벽히 정의할 때까지 솔루션을 만지지 말라는 교조주의는 현실에서 작동하지 않는다. **사람들은 실제로 동작하는 구체적 솔루션을 보았을 때 비로소 자신의 진짜 문제가 무엇이었는지 깨닫는다. 따라서 두 공간은 나선형으로 상호작용**해야 한다.
