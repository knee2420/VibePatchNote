# summary
강력한 디스커버리를 수행하지 못하는 PM들은 대개 4가지 근본 취약점에 시달린다. **비즈니스 모델에 대한 깊은 이해 부족, 자신에게 유리한 데이터만 편향 수집, 엔지니어를 단순 하청으로 대하는 태도, 모든 것을 다 하려는 우선순위 실패**를 리더가 적극 코칭해야 한다.

| E2 | 안티패턴 | 확증 편향적 데이터 해석 | 자신의 아이디어를 정당화하기 위해 데이터를 취사선택하고 고객 목소리를 왜곡 | `# More PM Problem Areas` |
| E3 | 규칙 | 엔지니어와의 신뢰 구축 | 엔지니어에게 문제를 공유하지 않고 솔루션 스펙만 던져주는 일방통행 금지 | `# More PM Problem Areas` |
| E4 | 규칙 | 가장 중요한 리스크에 집중 | 사소한 엣지케이스에 매달리지 않고 생존을 결정짓는 핵심 리스크를 먼저 타격 | `# More PM Problem Areas` |
