# 이 섹션은

캔버스 노드, 엣지, 핸들, 플로팅 툴팁, 줌 컨트롤 등 우리 프로젝트의 `apps/web/src/shared/ui/`에 즉시 복사하여 사용할 수 있는 17개 핵심 컴포넌트 목록입니다.

# 카드

| 카드 | 핵심 가치 (값나가는 것) | elements |
|---|---|---|
| [Base Node Component](C-base-node.md) | 헤더, 타이틀, 본문, 푸터 레이아웃과 선택 상태 스타일이 결합된 표준 캔버스 카드 | 3 |
| [Database Schema Node](C-database-schema-node.md) | 테이블 명칭, 키 타입 및 다중 필드 행 목록을 표시하는 스키마/데이터 테이블 전용 노드 | 3 |
| [Labeled Group Node](C-labeled-group-node.md) | 캔버스 위의 여러 노드를 시각적으로 묶어주는 영역 래퍼 및 그룹 라벨 컴포넌트 | 3 |
| [Placeholder Node](C-placeholder-node.md) | 데이터 로딩 중이거나 드롭 대기 상태를 나타내는 플레이스홀더/스켈레톤 노드 | 3 |
| [Node Tooltip Component](C-node-tooltip.md) | 노드나 캔버스 요소 호버 시 플로팅되는 고해상도 정보 툴팁 | 3 |
| [Node Status Indicator](C-node-status-indicator.md) | 노드의 실행, 완료, 에러, 대기 상태를 실시간 시각화하는 인디케이터 점/뱃지 | 3 |
| [Node Search Bar](C-node-search.md) | 캔버스 내 노드를 실시간 검색하고 해당 노드로 부드럽게 화면을 이동시키는 검색 위젯 | 3 |
| [Node Appendix Panel](C-node-appendix.md) | 노드 카드 외곽에 날개처럼 부착되어 추가 정보나 액션을 확장하는 부가 패널 | 3 |
| [Canvas Devtools Panel](C-devtools.md) | 캔버스 노드 수, 선택 상태, 뷰포트 x/y/zoom 좌표를 실시간 디버깅하는 개발자 패널 | 3 |
| [Zoom Select Dropdown](C-zoom-select.md) | 25%, 50%, 100%, 200%, Fit View 등 정형화된 줌 배율을 원클릭 선택하는 드롭다운 | 3 |
| [Zoom Slider Controller](C-zoom-slider.md) | 캔버스 줌 배율을 미세 조절하는 슬라이더 바 컨트롤러 | 3 |
| [Animated SVG Edge](C-animated-svg-edge.md) | SVG 패스를 따라 점이나 빛 파티클이 동적으로 흐르는 고품질 애니메이션 엣지 | 3 |
| [Button Edge Component](C-button-edge.md) | 엣지 중앙에 삭제, 분기, 설정 등의 액션 버튼이 부착된 인터랙티브 엣지 | 3 |
| [Data Edge Component](C-data-edge.md) | 연결선 위에 데이터 타입, 흐름 건수, 라벨 뱃지를 표시하는 데이터 플로우 엣지 | 3 |
| [Base Handle Component](C-base-handle.md) | 포트 호버 효과 및 연결 가능 상태를 시각화하는 표준 연결 핸들/포트 | 3 |
| [Button Handle Component](C-button-handle.md) | 클릭하여 즉시 새 노드를 생성하거나 팝오버 메뉴를 띄우는 버튼형 연결 포트 | 3 |
| [Labeled Handle Component](C-labeled-handle.md) | 입출력 파라미터명이나 데이터 타입 라벨이 나란히 표시되는 텍스트 라벨 포트 | 3 |
