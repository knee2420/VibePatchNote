# summary
Origin UI의 Label 컴포넌트 명세서. Renders an accessible label associated with controls. 지원 프리뷰 패턴: p-input-6.

# elements
| id | kind | label | 무엇이 들어있나 | anchor |
|---|---|---|---|---|
| E1 | 구조 | Label Anatomy | Label 컴포넌트의 슬롯 구성 및 계층 레이아웃 | `title` |
| E2 | 규칙 | Label Installation | CLI(`npx shadcn add`) 및 Manual 복사 설치 가이드 | `## Installation` |
| E3 | 사례 | Label Variants | 실무에 즉시 적용 가능한 파티클 변형: p-input-6 | `## Installation` |
