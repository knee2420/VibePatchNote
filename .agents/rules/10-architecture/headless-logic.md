# Headless Logic & UI Separation

## 원칙
1. **로직과 뷰의 철저한 분리**:
   - UI 컴포넌트(JSX/TSX)는 오직 화면 렌더링과 사용자 이벤트 전달만 담당합니다.
   - 상태(State) 관리, 데이터 변환, 비동기 API 통신, 유효성 검사 등 모든 비즈니스 로직은 **Custom Hook**(프론트) 또는 **Use Case**(백엔드)로 분리합니다. 백엔드의 `service.py` 는 유스케이스로 넘기는 얇은 경계일 뿐 로직을 소유하지 않습니다.

2. **재사용성 및 이식성 극대화**:
   - UI가 없는 순수 로직(Headless Hook)은 언제든 다른 UI(모바일 뷰, 다른 디자인 테마 등)에 바로 연결할 수 있어야 합니다.
   - 반대로 UI 컴포넌트 또한 특정 비즈니스 로직에 결합되지 않고 순수 Props 기반(Presentational)으로 동작하여 다른 프로젝트에 쉽게 복사해 쓸 수 있어야 합니다.
