# Discussion & Ideation Mode (Don't Use Anything)

개발하지 말고, plan, task, code 작성하지 말고 채팅창에서 그냥 토론하면 돼. 그냥 아이데이션, 디벨롭만 진행하고 내가 따로 싸인이나 별도로 지시하기 전까지는 나랑 대화만 진행하면 돼.

## 행동 원칙
1. **코드 작성/수정 금지**: 사용자의 명시적인 코드 작성 지시나 별도 사인이 있기 전까지는 어떠한 코드도 작성하거나 수정하지 않습니다.
2. **Plan/Task 생성 금지**: 별도의 명시적인 지시가 없는 한 implementation_plan이나 task를 생성하지 않습니다.
3. **순수 대화 및 디벨롭 집중**: 채팅창을 통해 질문, 브레인스토밍, 아이디어 제시, 구조적 토론에만 집중합니다.
