# What-s-in-my-head Frontmatter 규격 정의서

`What-s-in-my-head` 외부 프로젝트 매니지먼트(Obsidian Vault)의 `1.🎯(Project) 프로젝트` 영역에서 사용하는 표준 YAML Frontmatter 스펙입니다.

---

## 📋 표준 YAML 템플릿

```yaml
---
유형: 할일
구역: 1.project
분류:
  - 💻문서 어시스턴트 동작 구현
주제:
  - {{PROJECT_OR_TASK_TOPIC}}
상태: to do
요약: {{ONE_LINE_SUMMARY}}
작성일: {{YYYY-MM-DD}}
마감:
커버:
상위: "[[(layout 정비) IDE 패널 정비]]"
링크:
담당:
  - "[[민규 서]]"
작성자:
  - "[[민규 서]]"
일정:
---
```

---

## 🏷️ 속성별 세부 지침

| 속성 | 기본 권장값 | 설명 |
| :--- | :--- | :--- |
| **유형** | `할일` | 할일 태스크/명세서의 경우 `할일`로 지정. |
| **구역** | `1.project` | `What-s-in-my-head`의 1번 프로젝트 구역 식별자. |
| **분류** | `💻문서 어시스턴트 동작 구현` | 프로젝트 볼트의 대분류 카테고리 태그 리스트. |
| **주제** | 작업 맥락에 맞게 유동적 | 예: `문서 어시스턴트 에디터 package 리팩토링`, `Zustand Store 전환` 등. |
| **상태** | `to do` | 신규 위임 시 `to do`, 진행 시 `in progress`, 완료 시 `done`. |
| **요약** | 1줄 핵심 요약문 | 다음 작업자가 3초 만에 목표를 파악할 수 있는 단문. |
| **작성일** | `YYYY-MM-DD` | 위임서 생성 일자. |
| **상위** | `"[[(layout 정비) IDE 패널 정비]]"` | 옵시디언 위키링크 형태의 상위 에픽/마일스톤 문서 링크. |
| **담당** | `- "[[민규 서]]"` | 담당자 위키링크. |
| **작성자** | `- "[[민규 서]]"` | 작성자 위키링크. |
