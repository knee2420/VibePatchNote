# summary
지휘자(Desktop)에게 이전의 실패 맥락을 포함하여 목표를 공유한다. 그 결과 데이터 구조 사전 일괄 확장, 필터 원칙(원본 분리), 의존성 기반 작업 순서 등의 **정교한 아키텍처 v2와 세부 작업 지시서**를 확보한다. 

# elements
| id | kind | label | 무엇이 들어있나 | anchor |
|---|---|---|---|---|
| E1 | 절차 | 맥락 및 실패 공유 | Desktop에 현재 상태 파일과 "방금 이런 충돌이 있었다"는 실패 사실 전달 | `## 지휘자에게 상황을 공유한다` |
| E2 | 분석 | 4대 결정 포인트 | 데이터 구조 통합 확장, 필터 훅 분리, 소컴포넌트 분할, 안전한 순서 도출 | `## 지휘자의 분석` |
| E3 | 전략 | 질문을 통한 심화 | 마이그레이션 방안이나 필터 꼬임 문제에 대해 구체적으로 질문하여 설계 보완 | `## "이렇게 하면 되나요?" — 설계를 깊이 파고든다` |
