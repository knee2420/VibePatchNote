# 이 책은

**"모델에게 무엇을 시킬 수 있는가"에서 "모델이 일하는 환경을 어떻게 설계할 것인가"로**
관점을 옮기라는 한 문장을 15장에 걸쳐 전개한다. `Agent = Model + Harness`가 중심 공식.

자동차 배선 하네스와 소프트웨어 테스트 하네스에서 어원을 끌어와,
ReAct·Toolformer·SWE-agent 같은 연구, OpenAI·Anthropic 공식 문서, LangChain·Fowler의 개념화,
OWASP·NIST 안전 프레임워크까지 **공개 자료를 하나로 엮은 종합서**에 가깝다.
저자 고유 주장은 제12장(3가지 역발상)과 제14장(메모리 소유권·락인)에 몰려 있다.

**모든 장 끝에 일상 실습이 붙는다** — 가족 여행, 이사 준비, 냉장고 식단, 독서 노트,
아침 루틴. 비개발자도 따라올 수 있게 하려는 편집 방침이고,
`harness-lab`이라는 실습 스킬 설치가 전제다.

[1권 하네스 엔지니어링 입문](../하네스_엔지니어링_입문/index.md)과 비교하면 **14배 분량**이고,
입문서가 4구성요소로 좁게 정리한 것을 이쪽은 15장으로 넓게 편다.
