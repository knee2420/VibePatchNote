# 이 폴더는

"기억하는 개발" 워크플로우를 실제 프로젝트(할일 앱) 확장에 적용해본다. 

아무것도 없는 백지상태에서 시작하는 것과, 이미 돌아가고 있는 기존 코드 위에 복합 기능(마감일, 카테고리, 필터)을 얹는 것은 전혀 다른 차원의 문제다. 이 폴더에서는 Claude Code에게 **지휘자(Desktop)의 설계 없이 단독으로 시켰을 때 벌어지는 참사**를 먼저 경험하게 한 뒤, 아키텍처 문서를 통한 치밀한 오케스트레이션이 어떻게 이 모든 문제를 사전에 차단하는지 증명한다. 더불어 발생한 에러를 분석하고 3단계로 대응하는 구체적인 실무 트러블슈팅 가이드를 제공한다.
