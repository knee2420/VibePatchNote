# 이 폴더는

책이 '판단의 길'이라 부른 구간이자 **이 책의 결론부**. 앞의 개념·구현·운영을
"그래서 우리는 뭘 고를 것인가"로 수렴시킨다.

네 장의 성격이 다 다르다. 제11장=**패턴 카탈로그**(12개), 제12장=**의사결정 도구**(7결정+3역발상),
제13장=**논거 종합**(왜 하네스가 성능을 좌우하나), 제14장=**전략**(메모리 락인),
제15장=**사례집**(기업 11곳).

**제12장의 3역발상과 제14장의 락인 논의가 이 책에서 가장 독자적인 부분**이다.
나머지는 대체로 공개 자료의 정리에 가깝다.
