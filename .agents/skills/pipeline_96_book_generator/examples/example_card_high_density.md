# summary

**논거 종합 장.** 모델 비교에서 환경 설계로 시선을 옮기라는 주장을
LangChain의 정의, SWE-agent의 연구 근거, OpenAI의 실무 사례 순으로 쌓는다.

E2("모델이 아니라면 모두 하네스다")와 E3(ACI — 인터페이스가 성능을 만든다)가 이 장의 두 기둥.
E4(UI/UX, 5.8KB)는 **이 책에서 비개발 직군을 정면으로 다루는 유일한 절**이다.

# 밖으로

- E13의 최소 하네스가 **4가지**인데 [C-01-01 제1장](../01_하네스의기초/C-01-01_제1장-하네스의탄생.md) E9는 **5가지**다. ⚠️원문이 5→4 축소를 설명하지 않음
- E9(엔트로피·GC)는 [C-03-03 제10장](../03_평가와운영/C-03-03_제10장-안전거버넌스.md) E9와 같은 주제. 세 곳(10장·12장·13장)에 흩어짐
- E16 문장이 [C-05-01 맺음말](../05_실습과참고자료/C-05-01_맺음말.md)의 '업무 운영체제'와 같은 은유
- E4(UI/UX)는 [C-05-09 부록H](../05_실습과참고자료/C-05-09_부록H-QA.md) '9. UI/UX와 제품 적용' Q50~Q55와 짝
- E12 반복 5패턴과 [C-04-01 제11장](C-04-01_제11장-12패턴.md)의 12패턴이 **서로 참조하지 않는다.** 5와 12의 관계가 정리 안 됨
