# 리뷰 코멘트 템플릿

볼트 코멘트 형식(`What-s-in-my-head/docs/comments.md`)입니다. 플러그인은 **머리줄 `> **이름** · YYYY-MM-DD HH:mm` 모양과 맨 끝 `^c-…` 줄**로 스레드를 읽습니다. 둘 다 지키세요.

## 1. 본문 — 틀린 줄 끝에 앵커

```text
* **허브 링크**: https://example.go.kr/forms/list.do [[#^c-r1a2b3c4|💬]]
```

`c-` 뒤 8자는 소문자 · 숫자. 카드 안에서 겹치지 않게 만듭니다.

## 2. 카드 맨 아래 — 스레드 열기 (`+` = 펼침 · 안 닫힘)

```text
## 💬 코멘트

> [!comment]+ 💬 **허브 링크**: https://example.go.kr/forms/list.do
> **Claude** · 2026-10-26 09:40
> [R-LINK] 이 주소를 열면 제목이 「오류페이지」(404) 입니다.
> 확인: 2026-10-26 09:38 브라우저로 직접 열어 봄.
> 방향: 기관 메인에서 서식 메뉴의 실제 링크를 따라가 목록 페이지 주소를 쓰세요. → lessons_learned L-02

^c-r1a2b3c4
```

* 첫 줄 `💬` 뒤는 앵커를 단 줄의 앞부분(인용). 길면 `…` 로 자릅니다.
* 본문 셋: **무엇이 틀렸나 · 어디서 어떻게 확인했나 · 고치는 방향.** 고친 문장을 대신 쓰지 않습니다.
* `lessons_learned` 에 같은 항목이 있으면 ID 를 붙입니다.

## 3. 작업자 답글 (작업자가 `^c-…` 바로 위에 덧붙임)

```text
>
> **Antigravity** · 2026-10-26 10:12
> 고침: 서식 메뉴 → 「법률서식」 목록 페이지로 바꿈. 근거: 그 페이지에 「총 2148 개의 게시물」.
```

## 4. 리뷰어가 닫기 (`+` → `-`, `💬` → `✅`)

```text
> [!comment]- ✅ **허브 링크**: https://example.go.kr/forms/list.do
> **Claude** · 2026-10-26 09:40
> [R-LINK] …
>
> **Antigravity** · 2026-10-26 10:12
> 고침: …
>
> **Claude** · 2026-10-26 10:30
> 확인함 — 새 주소 200, 목록 · 건수 보임, 재촬영 캡처와 레이아웃 같음.

^c-r1a2b3c4
```

스레드는 지우지 않습니다. 닫힌 스레드는 토론 패널의 `✅ 해결됨` 아래로 접힙니다.

## 지적 ID

| ID | 뜻 |
| :--- | :--- |
| `R-GATE` | 기계 검사 FAIL (02 출력 그대로 붙임) |
| `R-LINK` | 열리지 않음 · 로그인 · 다른 사이트 · 짐작 URL |
| `R-IMG` | 캡처가 그 페이지가 아님 · 그린 그림 · 목록이 가려짐 |
| `R-FACT` | 숫자 · 문구가 페이지에 없음 / 캡처와 본문이 다른 말 |
| `R-SCOPE` | 허브가 아님 (서식 한 장 · 사이트 메인) · 카드 주제와 안 맞음 |
| `R-LICENSE` | 이용 조건 누락 · 재배포 · 상업 이용 판단 누락 |
| `R-STYLE` | 볼트 규칙 (속성 · 작성자 · 뺀 후보 표 없음 등) |
